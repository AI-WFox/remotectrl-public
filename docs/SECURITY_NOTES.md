# Security Notes

RemoteCtrl is designed for consent-first classroom demonstration and small LAN lab use.

## Non-Negotiables

- No stealth execution.
- No hidden background keylogger.
- No arbitrary file traversal outside allowed roots.
- No unlogged remote command.
- No power action without local confirmation.

## Defaults

- Power commands run in dry-run mode unless `REMOTECTRL_ENABLE_POWER_ACTIONS=true`.
- Agent file access starts with the user's home directory only.
- Enrollment tokens are generated by the backend and stored hashed.
- WebSocket messages include `agent_id` and `command_id`.

## Production Gaps

Before commercial or Internet-facing deployment, add:

- TLS termination and secure cookies.
- PostgreSQL migrations.
- Strong password hashing with passlib/argon2.
- Per-user RBAC.
- Device attestation.
- Signed agent builds and auto-update.
- Rate limits and IP allowlists.
