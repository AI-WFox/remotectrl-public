# Security Notes

RemoteCtrl is designed for consent-first classroom demonstration and small LAN lab use.

## Non-Negotiables

- No stealth execution.
- No hidden background keylogger.
- No arbitrary file traversal outside allowed roots.
- No unlogged remote command.
- No remote action without local confirmation by default.
- No persistent never-ask-again approval bypass.

## Defaults

- Every remote action, including stopping an active session, requires local approval by default.
- Agent users may choose `Allow this action for this session`; that cache is runtime-only and resets on disconnect/restart/manual reset.
- Power commands run in dry-run mode unless the Agent config sets `dry_run_power=false`.
- Agent file access starts with no allowed folders; the local Agent user must add each root explicitly.
- Enrollment tokens are generated by the backend and stored hashed.
- WebSocket messages include `agent_id` and `command_id`.

## Production Gaps

Before commercial or Internet-facing deployment, add:

- TLS termination and secure cookies.
- PostgreSQL migrations.
- Password hashing is currently PBKDF2-HMAC-SHA256 for the demo; migrate to Argon2id before commercial deployment.
- Per-user RBAC.
- Device attestation.
- Signed agent builds and auto-update.
- Rate limits and IP allowlists.
